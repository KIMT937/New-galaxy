# 🚀 갤럭시 아케이드 (Galaxy Arcade)

> 1980년대 클래식 오락실 명작 갤러그(Galaga)와 갤럭시안(Galaxian)의 감성을 현대적인 React & TypeScript & HTML5 Canvas로 재해석한 정통 레트로 우주 슈팅 아케이드 게임입니다.

---

## ❓ 깃허브(GitHub)에서 바로 실행되지 않는 이유 및 해결 방법

본 프로젝트는 최신 **React 19 + TypeScript + Vite** 기반의 고성능 웹 애플리케이션입니다.  
일반 정적 HTML 파일과 달리 소스 코드(`.tsx`)와 모듈 시스템을 사용하므로, **깃허브 저장소에서 단순히 `index.html` 파일을 클릭하거나 더블 클릭하는 것으로는 브라우저 보안 정책(CORS 및 ES 모듈 로딩)상 바로 실행되지 않습니다.**

아래의 두 가지 방법 중 하나를 선택하시면 어디서나 손쉽게 플레이하실 수 있습니다!

---

### 방법 1. 깃허브 페이지(GitHub Pages)로 웹에서 바로 실행하기 (추천 ⭐)

저장소에 이미 GitHub Pages 자동 빌드 워크플로우(`.github/workflows/deploy.yml`)가 구성되어 있습니다.

1. 본인의 **GitHub 저장소 페이지**로 이동합니다.
2. 상단 메뉴에서 **[Settings]** 탭을 클릭합니다.
3. 좌측 사이드바에서 **[Pages]** 메뉴를 선택합니다.
4. **Build and deployment** 항목의 **Source**를 `Deploy from a branch`에서 **`GitHub Actions`**로 변경합니다.
5. 상단 **[Actions]** 탭에서 배포 완료(녹색 체크표시)를 확인한 후 안내된 주소(`https://<아이디>.github.io/<저장소명>/`)로 접속하면 브라우저에서 바로 게임을 플레이할 수 있습니다!

---

### 방법 2. 내 컴퓨터(로컬)에서 직접 실행하기

컴퓨터에 [Node.js](https://nodejs.org/) (버전 18 이상 권장)가 설치되어 있다면 명령창(터미널)에서 1분 만에 실행할 수 있습니다.

```bash
# 1. 저장소 클론 (다운로드)
git clone https://github.com/사용자아이디/저장소명.git
cd 저장소명

# 2. 필수 라이브러리 설치
npm install

# 3. 개발 서버 실행
npm run dev
```

터미널에 표시되는 로컬 주소(기본: `http://localhost:3000`)를 브라우저 주소창에 입력하면 즉시 게임이 실행됩니다.

---

### 방법 3. 배포용 파일 빌드 및 정적 미리보기

```bash
# 최적화된 정적 웹 파일 생성 (dist 폴더 생성)
npm run build

# 빌드 결과물 로컬 미리보기 서버 구동
npm run preview
```

> **참고**: `vite.config.ts`에 `base: './'` 상대 경로 설정이 적용되어 있어, `npm run build` 시 생성되는 `dist` 폴더 내부의 결과물은 어떤 웹 서버 호스팅에서도 경로 오류 없이 안전하게 실행됩니다.

## 🎮 게임 주요 시스템 & 특징

- **편대 비행 & 급강하 요격**: 외계 함선들이 곡예 비행으로 진형을 갖추고, 플레이어를 향해 위협적인 급강하 폭격을 감행합니다. (급강하 중 격추 시 **점수 2배**)
- **듀얼 파이터 (Twin Fighter) 합체**: 2대의 전투기가 하나로 도킹하여 2배의 화력으로 적을 압도합니다. 피격 시 1기만 희생되어 생존율이 대폭 증가합니다.
- **거대 모함 보스전 (Boss Dreadnought)**: 매 4스테이지마다 출현하는 거대 보스와의 다단계 격전 (실드 방어막, 양 날개 포탑 레이저, 유도 미사일, 분노 모드)
- **챌린지 보너스 스테이지**: 매 3스테이지마다 적들이 탄환을 쏘지 않고 곡예 편대 비행을 펼칩니다. (24기 전원 격추 시 **10,000점 퍼펙트 보너스**)
- **보급 캡슐 파워업**: 
  - `2X` : 듀얼 파이터 합체
  - `SP` : 3방향 확산 스프레드 샷
  - `PL` : 적을 관통하는 플라즈마 캐논
  - `RP` : 공격 속도 2배 래피드 파이어
  - `SH` : 기체 주변 에너지 보호막
  - `BM` : 화면 내 모든 탄환을 소멸시키는 EMP 스마트 폭탄
  - `1UP` : 보너스 목숨 추가
- **순수 8비트 Web Audio API 사운드**: 외부 음원 파일 없이 브라우저 자체 신시사이저로 8비트 레이저음, 폭발음, BGM 실시간 생성
- **CRT 오락실 필터**: 클래식 브라운관 모니터 주사선 효과 지원
- **명예의 전당**: 로컬 저장소 연동 3자리 이니셜 등록 랭킹 시스템

## 🕹️ 조작 방법

| 키 / 버튼 | 동작 |
| :--- | :--- |
| **방향키 `←`, `→` 또는 `A`, `D`** | 전투기 좌 / 우 이동 |
| **스페이스바 (`Space`) 또는 마우스 클릭** | 레이저 무기 발사 |
| **`B` 키 또는 폭탄 버튼** | EMP 스마트 폭탄 기폭 |
| **`P` 키** | 게임 일시정지 (PAUSE) |
| **화면 터치 & 마우스 드래그** | 기체 자유 이동 및 조준 (모바일/태블릿 최적화) |
| **AUTO FIRE 버튼** | 자동 연사 모드 토글 |

## 🛠️ 기술 스택

- **Frontend**: React 19, TypeScript
- **Styling**: Tailwind CSS v4
- **Graphics**: HTML5 2D Canvas (60 FPS Vector Sprites, Parallax Starfield, Particle FX)
- **Audio**: Web Audio API (Synthesized 8-bit Chiptune & Sound Effects)
- **Icons**: Lucide React
- **Build Tool**: Vite 8
